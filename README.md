# 🛍️ Technology & Clothes Store Sales & Performance Analytics

A comprehensive, multi-page business intelligence and data analysis project using **T-SQL (SQL Server)** and **Power BI** to evaluate multi-year retail performance, customer demographics, and product inventory insights.

---

## 📂 Repository Structure & Project Files

This repository contains all necessary resources to run, review, and interact with the project:

* 📊 **Interactive Power BI Report:** [`Retail Stores Sales Analytics.pbix`](./Retail%20Stores%20Sales%20Analytics.pbix) *(Download & open in Power BI Desktop for full interactivity)*
* 📜 **SQL Query Script:** [`Technology & Clothes Store.sql`](./Technology%20%26%20Clothes%20Store.sql) *(T-SQL script for querying, data management, and business aggregations)*
* 🖼️ **Executive Dashboards:** High-resolution preview screenshots included below.

---

## 📌 Project Overview
Retail operations across multiple categories (Electronics and Clothing) generate complex transactional data. This project investigates sales dynamics, financial metrics, payment preferences, regional distribution, and customer loyalty tiers across the years 2022 to 2024. The insights are visualized into an executive multi-page Power BI dashboard suite.

## 🛠️ Technologies Used

---

## 🚀 How to Run & Use
1. **Clone or Download:** Clone this repository to your local machine.
2. **Database Setup:** Import the underlying retail dataset into your SQL Server database.
3. **Execute SQL Analytics:** Run the [`Technology & Clothes Store.sql`](./Technology%20%26%20Clothes%20Store.sql) script to execute the database operations and analytical queries.
4. **Interactive Dashboard:** Download and open the [`Retail Stores Sales Analytics.pbix`](./Retail%20Stores%20Sales%20Analytics.pbix) file in **Power BI Desktop** to explore the visualizations and interact with dynamic slicers.
